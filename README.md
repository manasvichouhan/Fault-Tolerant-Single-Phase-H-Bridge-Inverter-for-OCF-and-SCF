# Fault-Tolerant-Single-Phase-H-Bridge-Inverter-for-OCF-and-SCF
Project Overview

Developed and implemented a MATLAB/Simulink model of a single-phase H-bridge inverter to study fault detection and fault-tolerant operation.

Objectives

Simulate normal inverter operation.

Analyze open-circuit and short-circuit fault conditions.

Study fault detection and the potential use of a redundant leg to maintain operation.

Tools Used

MATLAB

Simulink

Power Electronics

Project Files

Simulink model: Main inverter circuit and control system.

MATLAB scripts: Fault detection and control logic, if implemented.
